# Cisco Networking Academy — Network Technician Labs

A collection of hands-on networking simulations, device configurations, and troubleshooting activities completed as part of the Cisco Networking Academy Network Technician career path.

---

## Technical Skills Demonstrated

* **Networking Protocols & Concepts:** TCP/IP, Ethernet, IPv4 Addressing, DHCP IP Pools, DNS, ICMP (Ping / Traceroute)
* **SOHO & Enterprise Administration:** Cisco Router & Access Point Configuration, Web GUI Administration, Password Security Policies
* **Wireless Security:** 802.11 Wi-Fi Setup, SSID Broadcast Management, WPA2-Personal (AES) Encryption & Pre-Shared Keys
* **Physical Media & Cabling:** Coaxial Cabling, Copper Straight-Through, GigabitEthernet/FastEthernet Interface Management
* **Simulation Tools:** Cisco Packet Tracer
